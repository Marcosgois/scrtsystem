Governança de mainframe · SCRT · Tailored Fit Pricing

Todo o consumo IBM Z dos seus clientes, sob controle.

Consumo SCRT, contratos de MLC, inventário de software licenciado, parque físico e o ciclo de MO/MES — num só painel, com acesso por cliente.

Cinco módulos

Consumo zOTC

Leitura do SCRT, MSU por máquina e LPAR, baseline, comparativo mês a mês e projeção de capacidade.

Consumo MLC

Contrato de MLC por cliente e por ano contratual, com o consumo sincronizado do SCRT.

Inventário

Relatório IBM SW Material: PIDs, licenças e o casamento 1:1 com o S&S, com marcação de Demo/PoC.

Infraestrutura

Sites, máquinas e LPARs, referência de capacidade LSPR e o histórico de cada máquina.

Contratos

Contratos e termos aditivos ligando máquinas e PIDs, com os PDFs assinados e o ciclo de MO/MES.

Rodar na sua máquina

Clone e instale — git clone git@github.ibm.com:marcosgois/zControlDesk.git && cd zControlDesk && npm install
Suba — npm start. Um MongoDB local sobe junto, com os dados em ./data; nada é instalado no sistema.
Abra http://localhost:3000 — no primeiro acesso o sistema pede a criação do administrador. Depois é o admin quem cadastra os demais usuários.
Para usar o banco do servidor, defina MONGODB_URI no .env. O README traz o procedimento de sincronização (npm run db:pull).
